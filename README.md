# Lab1_POO

## Programación Orientada a Objetos - Laboratorio 1

Este repositorio contiene ejercicios básicos de Programación Orientada a Objetos (POO) en Java.

### Conceptos Demostrados

1. **Encapsulación**: Atributos privados con getters y setters
2. **Herencia**: Clase `Person` como clase base, `Student` y `Employee` como clases derivadas
3. **Polimorfismo**: Sobrescritura del método `displayInfo()`
4. **Abstracción**: Organización de datos y comportamientos en clases

### Estructura del Proyecto

```
Lab1_POO/
├── src/
│   ├── Person.java      # Clase base
│   ├── Student.java     # Clase derivada (Estudiante)
│   ├── Employee.java    # Clase derivada (Empleado)
│   └── Main.java        # Programa principal
└── README.md
```

### Cómo Compilar y Ejecutar

1. **Compilar el proyecto:**
```bash
cd src
javac *.java
```

2. **Ejecutar el programa:**
```bash
java Main
```

### Salida Esperada

El programa demuestra:
- Creación de objetos de diferentes clases
- Uso de herencia y polimorfismo
- Encapsulación de datos
- Arreglos polimórficos
